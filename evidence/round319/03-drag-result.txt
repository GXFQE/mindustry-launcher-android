第 319 轮：主界面启动项的手工顺序（长按最左图标拖动）—— 真机记录
设备：HONOR ELP-AN00 / Android 16（API 36）· 开发版（DEBUGGABLE=true SUFFIX=-dev）

【拖之前的 config.json】没有 main_order 这个键（功能没开 ⇒ 与以前完全同一份配置）。

【把第 3 行「用于测试克隆功能」拖到最顶之后】
  adb shell input draganddrop 114 2414 114 1740 1500
  config.json 里出现（原样摘录）：
    "main_order": [
      "com.github.tinylake.mindustryX\u0000用于测试克隆功能",
      "io.anuke.mindustry",
      "com.github.tinylake.mindustryX",
      "import:official-159.apk",
      "import:official-159.apk\u0000test"
    ]
  ★ 键的形状：主行 = 版本 key（没有 \u0000）；附加行 = 版本 key + \u0000 + 它绑的槽。
    这正是 Versions.orderKey —— 不是 rowKey（rowKey 跟着当前槽走）。

【force-stop 再启动（判据 = 新进程重新扫、重新读 config）】
  uiautomator dump 的行顺序（只摘可见的三行）：
    用于测试克隆功能  改端  2026.09.X37（160.1）
    Mindustry  原端  159.7
    MindustryX  改端  2026.09.X37（160.1）
  ⇒ 顺序确实从 config 恢复，不是内存里那一份。

【拖到屏幕下边缘（自动滚动）】
