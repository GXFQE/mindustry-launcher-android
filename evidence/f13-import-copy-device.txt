── ✅ 第三批（用户三点）：类型组合 / 多人游戏 /「加载会失败」──
① 「怎么都是仅声明」的两个原因：
   (a) 我的锅：演示槽原来塞的是 17 个「只有 mod.json」的元数据副本 ⇒ 每个都"声明 java 无 dex"；
   (b) 判据错：把「meta 声明 java」当成了类型。真相 = 它是一条警告（见下）。
   已把演示槽换成 PC 上的**真实模组包**。
② 类型改成位掩码组合式（JAVA_DEX / JAVA_CLASS / JS / DATA）：4 位 = 16 种组合，
   枚举字符串必然漏 —— 用户说的 "json 混合 js" 正是我漏掉的那类。实测：
   · 原版瘤液拓展.zip   ⇒ JS 脚本（28 个 .js）＋Java（classes.dex）＋资源
   · 饱和火力3.3.0.zip  ⇒ JS 脚本（17 个 .js）＋Java（classes.dex）＋资源
   · 蓝钢工业拓展包(1).zip ⇒ 数据模组（JSON + 资源）
   · blackdeluxecatschematicparse.zip ⇒ Java（classes.dex）＋资源
③ ★★「加载会失败」：meta 声明 java 但没有 classes.dex ⇒ 安卓 DexClassLoader 找不到类 ⇒
   游戏 Failed to load mod file … Skipping.、整个模组被跳过。实测反例：
   · 逻辑工具v1.1.135.jar（java=true + 150 个 .class、无 dex）⇒ 徽标「加载会失败」+ 详细说明。
④ ★ 多人游戏（用游戏自己的判据与标签）：
   · Mods.java:950 getModStrings() 只收 !hidden && enabled（发给服务器比对「名字:版本」）；
   · ModsDialog.java:369 对 hidden 显示 @mod.multiplayer.compatible＝「支持多人游戏」；
   · Mods.java:1190-1192 插件（Plugin）会被游戏自动当作 hidden。
   实测：blackdeluxecatschematicparse / 逻辑工具（都 hidden=true）⇒「支持多人」；
         蓝钢工业拓展包 / 原版瘤液拓展 / 饱和火力（hidden 未写）⇒「联机需同款同版本」。
