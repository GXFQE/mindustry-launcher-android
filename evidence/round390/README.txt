第 390 轮证据：补丁行的描述重复 / 截断 / 分隔符混用
==================================================

用户
----
「长度超了被截断了」「描述重复（原端/本体+补丁）」「分隔符空格和点混用」

旧显示（真机）
--------------
`v1607  原端  160.7 · 本体+补丁（MindustryX (原版 + 补丁)）`

三个问题：
1. 太长了，`TextView` 是 `singleLine + ellipsize=END` ⇒ 尾部被截掉；
2. 标题已经有「原端」，后面再写「本体+补丁」= 同一件事说两遍；
3. 标题用两个空格分隔，后缀用 ` · `，两种分隔符混在一行。

修法
----
- 槽页所有版本行统一用 ` · ` 分隔（`prettyName`）；
- 带补丁行把类型词换成 `半改端`（不再追加「本体+补丁」）；
- 补丁名只留短名：去掉 `(...)` / `（...）` 解释（`MindustryX (原版 + 补丁)` → `MindustryX`）；
- 多个补丁用首条 id + `+N`，避免不同补丁组合显示名相同被合并。

新显示（真机截图 `slot-row.png`）
--------------------------------
```
v1607 · 半改端 · 160.7 · MindustryX      13 分钟
official1604.apk                         7 分钟
v1607 · 原端 · 160.7                      6 分钟
v160 · 原端 · 160                          5 分钟
```
- 行完整显示，没有省略号；
- 本体 / 带补丁用「原端 / 半改端」区分，不再重复；
- 四行都是同一个 ` · ` 分隔符。
