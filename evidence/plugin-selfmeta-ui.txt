## 3) 门禁抓到的真坑 🔴：别拿"字符串末尾的空格"当分隔符

第一版把标签写成 `作者： `（末尾一个空格），想着与值拼起来就是「作者： mdt」。**构建直接失败**：

```
RES-04  app/res/values/strings-plugin.xml:60 key 'plugin_info_author' 的值有真的前导/尾随空白
        （aapt2 会剥掉，装机后一个不剩）—— 要留白请写 \u0020
```
⇒ 就算它放过去，装到机器上也会变成「作者mdt-fixture」**连体字**（编译器、编译产物、肉眼都看不出）。
改法 = 标签自带 **`%1$s` 占位符**（`作者：%1$s`），拼接由 `String.format` 做 ⇒ 分隔符与语序都跟着语言走，
英文那份写 `Author: %1$s` 也自然。自检补了两条：标签必须含 `%1$s`、以及**实拼一次**（防"占位符数量/类型不对"
这种只在运行期炸的错）。
