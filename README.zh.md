# MDT 管理器 —— Mindustry（像素工厂）安卓多版本管理器

官方的 Mindustry 安卓版**一次只能装一个版本**，装第二个就把第一个覆盖掉；存档也只有一份，
换版本玩就等于把旧存档顶掉。这个管理器给每个版本一个**独立的「存档槽」** —— 多个版本同时装着，
各自的**存档 / 地图 / 蓝图 / 模组**互不干扰。

> ⚠️ **目前只有预览版（Pre-release），功能还没做完** —— APK 挂在
> [Releases](https://github.com/GXFQE/mindustry-launcher-android/releases)
> （标着 Pre-release 的那个），也可以自己构建，见 [构建](docs/DEVELOPING.md#构建)。
> 预览版意味着：界面、数据格式、功能都还可能变，**别拿它当稳定版用**。
>
> 下面那份功能列表说的是**当前源码**，最新的预览版 APK 可能落后一点。

## 它解决什么

| 直接用官方安卓版 | 用这个管理器 |
|---|---|
| 一次只能装一个版本，装第二个 = 覆盖第一个；想回老版本得重装再倒存档 | 多个版本同时装（159.7 / 160.4 / MindustryX X37 …），点一下切换；「继续上次」直接接上上次那个版本 |
| 所有版本共用一份数据（存档 / 地图 / 模组 / 设置），切版本就是换掉那一份 | 每个版本一个**槽**：存档 / 地图 / 蓝图 / 模组 / 设置全独立，互不覆盖 |
| 备份只能自己把数据目录整个复制出来 | **自动备份**（逐槽设触发时长与保留份数），按内容去重、跨槽共用 —— 真机实测 3 个槽各 20 份备份，9.1 GB 的数据在盘上只占 **448 MB** |
| 删存档 / 地图 / 蓝图就是删了，误删只能重来 | 删这些东西**先挪进中转站**，能放回来 |
| 模组加载失败时游戏会说原因（缺依赖 / 版本过低 / 黑名单），但**两个模组覆盖了同一个东西**它不查 | **模组体检插件**逐条查：谁把谁打包进去了、结构缺件、依赖 / 重名 / 黑名单、版本门槛，上次游戏日志里怎么说 |
| 崩了有一份日志（也能导出），但**不会告诉你是哪个模组干的** | **崩溃分析**给出结论与依据；报告能带着结论一键导出，也能**先脱敏**再发 |
| 一张图里有多少矿、哪里能建，只能进游戏数 | 地图页直接给 **地矿 / 墙矿 / 可建造 / 核心区**，还能导出成 JSON / JSONL |
| 蓝图只告诉你尺寸和方块数，缺哪种方块要进游戏摆一次才知道 | 列表写明**缺哪几种方块**（和「可能认错」的地方） |
| 整包导出数据时，设置和登录身份会一起被带走（游戏不区分） | **分享包**在打包前剥掉登录身份、服务器记录和只对你有用的东西 |
| 想要新功能只能等官方更新 | 管理器能装**插件**加东西（还年轻：目前只能手动装 APK） |

**它是怎么做到的**：把官方 APK **原样当插件加载** —— 不重打包、不重签名、不改游戏包名。
游戏自身的校验、存档格式、模组生态都不受影响；管理器这边只负责给每个版本安排一个
独立的数据根，并在启动时把游戏引到那个目录去。

## 怎么用

1. **自己准备游戏 APK** —— 本仓库**不包含**游戏本体，请从官方渠道获取官方 Mindustry，
   或 MindustryX 等构建的 APK。（魔改过的包不一定能加载。）
2. **装上管理器** —— 从 [Releases](https://github.com/GXFQE/mindustry-launcher-android/releases)
   下载（标着 Pre-release 的那个），或者自己构建（见 [构建](docs/DEVELOPING.md#构建)）。要求
   **Android 8.0（API 26）** 及以上；开发期间在 **Android 16（API 36）** 真机上验证过。
3. **导入并开玩**：
   - 打开管理器 → 「添加游戏」点开二选一：「导入 APK」选你那份 APK
     （会复制一份到应用私有目录），或用「添加包名」扫描已经装在手机上的游戏；
   - 给它分配一个**槽**（不同版本用不同的槽，存档就不会互相覆盖）；
   - 点那个版本启动。「继续上次」直接回到上次启动的那个版本。

界面**跟随系统语言**：中文手机上是简体中文，其它语言显示英文（目前只有中文 / 英文两套翻译）。
**顶栏右上角的齿轮（设置）→ 界面语言**可以覆盖它，也能切回跟随系统；
想自己翻一份（哪怕只是改几句），见下面的「翻译文件」一行。

## 能做什么

### 版本
- 扫描**已装**的游戏，或**导入** APK 副本
- 一行一个启动项：点行启动，「槽」按钮换槽，长按看详情
- **同一个版本可以绑多个槽**：点行上的「管理」（或长按那一行）进版本页 →「克隆…」用另一个槽再加一项，
  共用同一份游戏本体（不复制 APK、不占额外空间），存档 / 设置 / 模组各在自己的槽里 ——
  想两套存档又不想复制几十 MB 时用这个。同一页里还有换槽、详情、命名、资源和删除：
  **删除**在还有别的行时只删这一行，删到最后一行才删整个版本 —— 已装版本的最后一行不删
  （那份在系统里，要删请到系统里卸载）
- 详情里有来源、大小、校验值、原始版本名、ABI、构建号、存档份数
- 长按版本 →「资源」：按类型导出游戏包里的资源（贴图 / 音效 / 音乐 / 地图 / 文本 / 字体等），只导出勾选的类型
- 版本号不同却共用一个槽时，那一行会提醒「存档会互相覆盖」
- **不跑的包直接拦下**：导入时和启动前各查一次（入口类 / native 库 / ABI / 对齐）
- 「继续上次」直接接上上次启动的那一行（同一个版本绑了多个槽时，回的是上次用的那个槽）

### 存档槽
- 一个槽 = 一整套数据：存档 / 地图 / 蓝图 / 模组 / 设置
- 新建在行里；改名 / 克隆 / 删除在右上角 **⋮**
- 克隆会先给源槽备份；删掉的槽连备份一起进中转站，能放回来

### 存档
- 列表带缩略图；读不出来的单独一行说明原因
- 能搜能排：名称 / 最新在前 / 体积
- 导入导出 `.msav`：可多选，也能选整包 zip
- 删除先进中转站；游戏在跑时拒绝删
- 自动备份：设触发时长与保留份数，覆盖前一定先备一份
- 备份去重：3 个槽各 20 份，9.1 GB 只占 **448 MB**
- 整槽导出 / 导入：一个 zip，三种合并方式（更新 / 补齐 / 覆盖）
- 分享包：发给别人前剥掉身份信息；自己换机用整槽导出
- 所有导出都能改成「直接分享」，不落盘

### 地图
- 卡片 + 预览图（本槽 / 游戏自带 / 模组自带）
- 资源统计（**官方插件 `mapstats`**）：地矿 / 墙矿 / 可采地板 / 加成地板 / 可建造 / 核心区（按星球），
  并带 JSON 导出（一张 `.json`、多张 `.jsonl`；详细 / 简洁；保存或分享）
- 导入导出 `.msav`：可多选、可打包；游戏或模组自带的图也能导出
- 把存档变成地图（可选源图补生成器设置）
- 搜索排序；删除走中转站

### 蓝图
- 列表缩略图，详情逐格预览
- 详情：用到的方块、缺哪些、技术细节
- 缺件提醒；拿不准时标「可能认错」
- 导入导出 `.msch`：可多选、可打包
- 搜索排序；删除走中转站

### 模组
- 逐个 / 批量启停（改游戏自己的开关，改前备份）
- 每个模组说明能不能加载、为什么
- 模组体检（**插件**，`plugins/mods-health`）：谁把谁打包进去了、结构缺件（声明 Java 却没代码 / 多脚本没 `main.js`）、缺依赖 / 依赖被关 / 循环依赖、重名、黑名单、版本门槛、**两个模组都覆盖同一张原版贴图 / 同一句原版文案**，以及上次游戏日志里怎么说
- 它的判定同时画成行徽标，并往「筛选与排序」里加两项（有冲突的模组 / 按冲突风险）
- 导入时就体检（单份与批量都算）：结果弹窗 / 批量报告里先说这个包会不会加载 —— **只警告、不拦**
- 搜索筛选排序；导入导出；删除；复制到别的槽

### 插件
- 入口在主界面顶栏（齿轮右边）：装一份 APK 给管理器加能力
- 装完要退出重开，页面上有「立即重启管理器」
- 一行一个：名字 · 状态 · 来源 · 崩了怎么处置
- 能打开它的页面、启用 / 停用 / 删除、看信息
- 能往几乎所有页面加一行、加一张卡或一个动作（启动游戏页和插件页除外）
- 能把结论挂到行上和卡片里（按信息 / 警告 / 问题分色），往「筛选与排序」加自己的一项，也能给模组详情页「它要过这几关」出结论
- 能读槽与内容、设置、日志、中转站、版本，也能直接打开文件
- 崩了不拖死管理器：再试 / 回滚 / 隔离，页面上会说清

### 中转站
- 删掉的东西先进这里，不会直接消失
- 能看到是什么、来自哪个槽、多大
- 放回去（默认来源槽）；也能彻底删除 / 清空
- 最多留 20 份（整个槽 3 个）

### 日志与设置
- 日志导出：原样，或脱敏（去掉路径 / 设备 / 账号相关）
- 运行日志页：管理器日志 / 游戏日志 / 崩溃堆栈分段
- 崩溃分析：点名模组并给依据；认不出就说认不出
- 深浅色、界面语言、翻译文件
- 设置：默认槽、崩溃提示、崩溃报告份数、中转站保留份数、自动清理、存储占用
- 关于页：版本 / 数据位置 / GitHub 仓库、Issues、GPL-3.0

## 现在还没有的

- **联网功能**：地图下载、论坛嵌入、检查更新、管理器自更新 —— v1 只做「本地」：
  扫描已装的 + 自己导入。不影响游戏本身，联机 / 服务器列表 / 游戏内下载照常能用
- **插件分发**：只能手动装 APK，没有市场、下载与更新检查
- **插件的数据面**：统计结果、游戏内那一侧还没有

## 不打算做的

- **上架 Google Play**：把别的 APK 当插件加载不符合它的政策，只能侧载
- **内置文件管理器**：导入导出走系统文件选择器（它也不是通用存档管理器）
- **插件沙箱**：插件与管理器同一个进程，「要碰什么」只是告知，不是权限墙 —— 只装信得过的
- **打包游戏本体**：版权归各自作者，请自行准备 APK
