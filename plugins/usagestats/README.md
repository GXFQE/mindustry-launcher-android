# usagestats（官方插件，v31，第 254~256 轮）

游戏**前台时长**：探针自己记账，数据落在插件自己的 `data/`；宿主不写流水、不解析账本。
展示放在宿主自己的页面里（2026-10-26 用户：「尽量不要放插件页」）：

- **槽页**（`slot: section` + `page: slot`）：一张「游玩时长」卡 —— 本槽合计 + **按游戏版本**分列；
  已装游戏原地更新后，更新前后是**两行**（老版本的时间不会被新版本顶走）；
- **主界面摘要卡**：总时长一行（`plugin.json` 的 `playtimeTotal` 声明一个整数文件，宿主只排版）。

## 组成

| 文件 | 作用 |
|---|---|
| `PlaytimeProbe` | `inProcess` 探针（20 秒采样 + `onForeground`）：累计本局前台毫秒，写**账本**与总数 |
| `UsageStats.createView` | 槽页的 section（本槽合计 + 按版本分列，同名版本显示层合并；默认收起 3 行，可展开 / 收起）；同时是插件自述的默认入口（插件页长按「打开」看总计 + 按槽分列） |
| `core/Playtime` | 纯函数：账本解析 / 写回 / 求和 / 按槽分组 / 显示层同名合并 / 毫秒→时分（PC 侧可测） |
| `tools/Check.java` | PC 侧判据自检（`build.sh check`，25 条） |

## 数据（都在 `<插件>/data/`，`ProbeEnv.dataDir()`）

```
ledger.tsv   8 列 TSV，一行一个「槽 + key + 版本号」
total.txt    一个整数毫秒（所有槽合计；主界面摘要卡读它）
```

`ledger.tsv` 每行：

```
槽 \t key \t tag \t 毫秒 \t 更新时间 \t title \t rawName \t upstream
```

| 列 | 内容 |
|---|---|
| 槽 | 槽名（控制字符写入时换空格） |
| key | **身份**：已装 = 包名；导入 = `import:<文件名>` |
| tag | **版本号**（`displayVersion`，如 159.7 / 2026.09.X37）—— 也参与行身份 |
| 毫秒 | 该槽里这个版本累计的**游戏前台**毫秒（单调时钟） |
| 更新时间 | 墙钟毫秒（只诊断） |
| title | 显示名快照（如 `MindustryX  改端  2026.09.X37`） |
| rawName | 原始 versionName（如 `8-official-2026.09.X37`） |
| upstream | 上游版本号（fork 才有，如 `160.1`；官方为空） |

- **两份都走「临时文件 + 改名」**（读到的永远是完整文件）；`total.txt` 由探针每次写账本时一起刷新。
- **行身份 = 槽 + key + tag**：已安装的游戏更新时包名不变、版本号会变 ⇒ 新建一行，老行保留自己的快照。
  同一个 tag 重复玩只覆盖毫秒数，不追加行。
- 旧格式照读（第 255 轮的 4 列 / 5 列）：4 列 tag 为空、5 列末列当 tag；下一次写入时补成新格式，
  老时间不丢。
- 旧版（第 254 轮）的"每局一个 `playtime.txt` 再求和"已废弃：读一次账本是 O(1)，主界面那一行
  才能在 UI 线程上读。

### 槽页列表：同名合并 + 折叠

- **显示层合并**：同一个槽里，如果同一个游戏版本因为「已装包 + 导入的同版本 APK / 换过包名」出现
  多行，页面按**显示名**（名字里已含版本号）合并成一行、时长相加；账本仍保留分行（原始记录不丢）。
  官方 / fork 同号但名字不同 ⇒ 不会误合。
- **默认只显示前 3 个版本**；更多时出现「还有 N 个版本 · 展开」，展开后出现「收起」。
  这样版本多了槽页不会被顶得太高（收起状态不持久化，重新进页面还是收起）。

## 口径

- 只算**游戏 activity 在前台**的时间（主菜单 / 暂停 / 编辑器都算，切到别的 App 不算）；
- 进程被杀最多丢一次采样间隔（20 秒），**只少不多**；
- 不读存档的 `playtime`（那个是"存档内已保存时长"，回档/删档/复制都会乱）。

## 已知边界

- **槽改名**：账本里记的是槽名，改名后旧数字留在旧名下（总数仍对，那个槽的分项会断）；
- 槽删除后它的数字仍在总数里（"总游玩时长"不因删档回落）；
- 只有**装了本插件之后**启动的游戏才有数据（宿主的 `UsageLog` 已在第 252 轮删掉，没有旧流水可回填）；
- 同一个版本号但内容不同的包（重打包 / 换签名）会合并成一行（版本号是给人看的号，不是文件哈希）；
- 版本被卸载后槽页仍能显示它（用账本里的 title/tag 快照）。

## 构建 / 自检

```bash
ANDROID_HOME=D:/AndroidSDK bash plugins/usagestats/build.sh          # 产出 usagestats.apk

```
