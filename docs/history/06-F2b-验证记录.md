★ **三个必须记住的坑**（详见 `FLOWS.md` F2b 坑 与 `REFERENCE` §22）：
① ListView 的 item 根 `layout_margin` **无效**（`AbsListView.LayoutParams` 不带 margin）⇒ 行距必须用「外层 padding + 内层卡片」两层；
② `<include>` 多次引用会产生**重复 id**，`findViewById` 只命中第一个（静默错绑）⇒ 必须从 include 的根开始找；
③ 顶栏标题色用 `@color/on_appbar` 而非 `@color/fg`，且深色顶栏必须配 `windowLightStatusBar=false`。
