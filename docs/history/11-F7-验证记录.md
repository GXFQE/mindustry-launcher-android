## F7 验证记录（2026-10-01，真机 <测试机型> / Android 16）

**需求**：**加一个可以查看日志的地方**（要不然日志记录没用）；**问题**：**游戏的版本号被折叠了**。

前一条是本项目从 M0 起就欠的账：本 ROM **滤掉应用自己的 main logcat**，
所以所有运行期证据一律**写文件**（游戏侧 `last_log.txt`、启动器侧 `hub/report-*.txt`），
而这些文件在此之前**只有 adb 取得出来** —— 对用户等于不存在。

### 交付

| 项 | 说明 |
|---|---|
| 日志页 | 新 `LogActivity` + `activity_log.xml`：**一页三卡**（游戏日志 / 启动器日志 / 崩溃报告） |
| 数据源 | `<数据根>/last_log.txt`、`hub/report-{launch,autobackup,settings,health,m3,devtool}.txt`、`<数据根>/crashes/*.txt` |
| 交互 | 报告用横向 chip 切换；一键复制（复制**显示出来的那段**）；崩溃超限时出现「清理最旧的 N 份」 |
| 视觉 | 正文 `monospace`；`[E]` / `Exception` / `Error` / `FAIL` 行染 `chip_fg_warn`；新 `ic_terminal` 图标 + `chip_tab_on/off` |
| 入口 | 设置页第 3 行「运行日志」（与「日志保留份数」相邻 —— 那项是"留多少份"，这项是"到哪看"） |
| 版本号修复 | `item_version.xml` 的 `ver_title` / `ver_sub` 放开到 `maxLines="2"`；`buildTitle()` 把版本号染 muted 色 + 0.87 字号 |

### 本轮新坑（详见 `REFERENCE` §27）

- ⚠️ ★ **`uiautomator dump` 的坐标是准的，但内容会被 ActionBar 遮住**：页面滚到底时，
  某一行可以"在无障碍树里位于 y=224"却**完全落在 ActionBar（0~319）覆盖区内**，
  此时 `input tap` 打在那行上会被 ActionBar 吃掉，**看起来像"控件点不动"**。
  本轮差点据此误判成"chip 的点击监听没生效"。判据：用 PIL 扫 `accent_soft` 色的像素行，
  与 dump 的 bounds 对齐；对不上就说明目标被遮挡 ⇒ **先把目标滚进可见区再点**。
- ⚠️ **APK 内二进制 XML 的字符串池编码不统一**：`AndroidManifest.xml` 是 UTF-16LE，
  `res/layout/*.xml` 是 UTF-8；`@+id/xxx` 被编译成整数 ID（字符串池里查不到）。
  ⇒ 用 `b'X' in data` 判断"资源有没有编进去"会**假阴性**。
- ⚠️ **`SpannableStringBuilder` 没有 `indexOf`**（它只实现 `CharSequence`）——
  要给某些行加 span，必须在**原始 String** 上定位下标，再 `setSpan` 到 builder 上。
- ⚠️ **设备 `sh` 的 `$(( ))` 是 32 位**：用 `$((1759300000000 + i*1000))` 造毫秒时间戳会**溢出成负数**，
  生成的文件名字典序全乱。造测试数据要用字符串拼接（`printf "175930000%04d" $i`）。
- ⚠️ **`rmdir` 之后 `ls -d` 返回非零**，会让 `&&` 链整条断掉（本轮踩了一次，后续命令全没跑）。
