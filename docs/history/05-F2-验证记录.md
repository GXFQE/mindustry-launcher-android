## F2 验证记录（2026-10-01，真机 <测试机型> / Android 16）

| 用例 | 结果 |
|---|---|
| 槽徽标 | ✅ 每行右侧 chip 显示该版本实际落点（`Config.slotOf` 命中时显示槽名，否则显示默认槽） |
| 同槽冲突 | ✅ 3 个版本同在 `default` ⇒ 3 行全红且**互相点名**；把其中一个改到 `test2` ⇒ 它立刻转正常色、**另两个自动改口**（对手动态重算） |
| 可见「槽」入口 | ✅ 行内按钮弹出 `pickSlot`（与长按那条路**同一个方法**）；**长按详情仍在**，两条路结果一致 |
| 继续上次 | ✅ 顶部按 `Config.lastVersion()` 显示，点它走 `startVersion` 同一条路径 |
| `dev_launch_key` | ✅ 仍命中（`com.github.tinylake.mindustryX` ⇒ 正常拉起游戏） |
| M3 自检 | ✅ **36 项全过 / 0 失败** |
| 主题 | ✅ 深色（背景 `#121212`）与浅色（`#FFFFFF`）均实拍；chip 两套值由 `values-night/` 正确切换 |
| 游戏侧回归 | ✅ 无 ActionBar / 无异常 |

★ **两个必须记住的坑**（详见 `FLOWS.md` F2 坑 与 `REFERENCE` §21）：
① 行内含可点击按钮 ⇒ item 根必须 `android:descendantFocusability="blocksDescendants"`；
② `Config.lastVersion()` 存的**不是** `Entry.key()`（导入版是 APK 文件名）⇒ 匹配要两种键都试。
★ **深色切换不能用 `cmd uimode night`**（这台 ROM 忽略它）⇒ 用 `settings put secure ui_night_mode 1|2`。
