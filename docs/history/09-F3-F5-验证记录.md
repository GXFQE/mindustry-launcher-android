### 交付

| 项 | 说明 |
|---|---|
| 设置页 | `SettingsActivity`（第 4 个页面）；全局项：**默认槽** + **日志保留份数** + 只读「关于」卡 |

| 策略入口 | 存档页槽菜单第 4 项「自动备份设置…」（**不放在设置页**，因为开关天然属于某个槽） |

★ **与桌面版刻意的两处差异**（定案）：
① 设置页**按 Android 语义拆开**（槽策略进槽菜单），不是照抄桌面版的两分区；
② **改一项立刻生效**，不做「保存并返回」。

### 最重要的一处更正：自动备份语义

旧文档写「启动前备份」，**与源码不符**。核对桌面版 `MDT-Dev/gui_game.py:490-510`：

```python
playtime = (time.time() - start) / 60
if auto_backup and playtime >= min_playtime:   # 默认 20 分钟
    create_backup()
```

⇒ 门槛量的是**上一局游戏的运行时长**，触发点在**游戏退出之后**。
Android 没有后台服务，用生命周期等价实现：`startVersion()` 记账（槽 + 时刻）→ `onResume()` 结算
（`settle()` **先清账再判断**，避免反复触发）。默认值照抄桌面版：`enabled=true` / `min=20` / `max=20`。

### 本轮新坑（详见 `REFERENCE` §25）

- ⚠️ **`session` 必须在 `settle()` 里先清**，否则每次 `onResume` 都会重判一次。
- ⚠️ **后台备份失败不弹 Toast**：最常见的"失败"是**新槽还没内容**，不是错误；异常吃在 `runNow()` 里、只写 report。
- ⚠️ **dev 与产品版产物又是同一个字节数**（108499）⇒ 继续不信字节数，读行为。
- ⚠️ **`run-as` 读不到 `/sdcard`** ⇒ 往内部文件灌内容用 `run-as ... sh -c 'cat > <path>'` + stdin 直灌。
- ⚠️ **UI 自动化改 EditText 不可靠**（软键盘弹出使旧坐标失效）⇒ 验证"配置 → 界面"链走 dev 口写配置 + 重开页面。
- ⚠️ **产品版 dev 口验证抓不到 Toast** ⇒ 改用副作用：确认 report 文件**未被改写**。
