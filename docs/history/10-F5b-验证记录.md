## F5b 验证记录（2026-10-01，真机 <测试机型> / Android 16）

**需求两条**：**竖屏也加上滚动** + **存档槽设置的 UI 也优化**。
前者是 F2c 遗留的**错误结论**（"竖屏刚好一屏、不用滚"从未被实测证伪），后者是 F3/F5 遗留的**视觉债**。

### 交付

| 项 | 说明 |
|---|---|
| 竖屏滚动 | 三页内容末尾各加一个 `@dimen/page_bottom_space`(24dp) 占位 `View`；**不动** `applySystemInsets()` 的四边语义 |
| 策略对话框 | `dialog_policy.xml`（XML 表单）+ `dlg_bg.xml`（16dp inset 卡片）+ `pol_live_bg.xml`（`accent_soft` 摘要条） |
| 对话框主题 | `AppTheme` 挂 `android:alertDialogTheme`；`AppDialogTheme` 在 `values/` 与 `values-night/` **各写一份** |
| 表单行为 | 实时摘要 / 关闭即置灰 / ★ **校验不过不关窗**（接管 `BUTTON_POSITIVE` 的 `OnClickListener`） |

### 本轮新坑（详见 `REFERENCE` §26）

- ⚠️ ★ **`input swipe` 在这台 ROM 上只有"慢拖"可靠**（如 `input swipe 20 2400 20 400 1000`）。
  快速 swipe（150~300ms）常被判成 fling 或丢弃 —— **连续几次"纹丝不动"会让人误判成"不能滚"**。
  `input keyevent 93`(PAGE_DOWN) 与 `input motionevent` 序列无效 / 不可靠。
- ⚠️ **换 `windowBackground` 会同时改变对话框可视宽度**：框架本就在对话框窗口根留 16dp inset
  （实测窗口 `[30,772][1193,1921]` → 可见卡片 `[82,824][1141,1869]`，差 52px = 16dp@520dpi），
  我们 `dlg_bg` 再叠 16dp ⇒ 总留白 32dp（有意，对齐卡片页边距）。
- ⚠️ **`values-night` 是整份替换语义** ⇒ `AppDialogTheme` 必须在那里**完整重写一遍**。
- ⚠️ **`setPositiveButton(..., null)` + `setOnShowListener` 接管点击**，是"校验不过不关窗"的唯一写法；
  旧写法点保存即关窗，非法值被静默丢弃、Toast 一闪而过。
- ⚠️ **F5b 之前"dev 比产品大 4.3KB"被误读成 debug 标志成本** —— 实为 F5b 新增资源的体量，
  `android:debuggable` 增量为 **0 B**（本批 dev 与产品再次**双双 112812**）。
