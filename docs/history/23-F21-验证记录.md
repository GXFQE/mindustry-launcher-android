- ✅ **数字口径统一**（2026-10-04，起因：沙子的数量在同一页出现两个值）：同一批格子会同时算
  「可采地板」与「加成地板」（沙地既掉沙又含油），第一版让两段分别显示"能采到"与"总格数"
  ⇒ 同名两个数看着像 bug。现在**每行头号数字一律「能采 X 格」，副行给「共 Y 格」**
  （只有「墙矿」段例外：行名带「（墙）」、且它本来就长在墙里 ⇒ 用总格数 + 摘要说明
  「长在墙里，需要用墙钻」）。
  证据：`evidence/f21-detail-bonus.png`（两段的沙子都是 `能采 13,976 格`＋`共 51,314 格`）。
- ✅ **两类矿的命名口径**（2026-10-04）：不要写"普通钻头采不了"、要写"需要使用墙钻"；
  矿分为**地矿 / 墙矿**、对应**地钻 / 墙钻** ⇒ 段标题 = **地矿** / **墙矿**；
  墙矿摘要 = `3 种 · 共 309 格（长在墙里，需要用墙钻）`，那一**段不报遮挡**（矿就长在墙里，
  说"在墙下"自相矛盾；全语料墙矿格 能采 3,701 / 墙下 112,207 ⇒ 3.2%）。
  ⚠️ 游戏自己的 zh_CN 里**没有**「地钻/墙钻」这些词（只有机械/气动/激光/爆破/冲击/爆裂钻头…）
  —— 这是玩家口径，界面上照这个写。
