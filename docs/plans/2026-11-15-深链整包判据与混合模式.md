# 深链整包判据（整槽 > 模组 > 蓝图/地图）与「混合模式」可行性

> 2026-11-15 第 379 轮。当前**已实现**的是判据与拒绝；「混合模式」是用户提的候选，**未开工**。
> 触发：用户报「从深链导入一个模组，识别成蓝图了」→ 两轮定案 → 又补三条约束（见下）。

## 一、用户的三句话（原文）

1. 「**感觉模组才应该是最优先的**」→ 又补：「**整个槽的优先级最高吧**，毕竟整个槽里什么都有，
   但是可能需要**严格检查格式**」
2. 「**注意检测到 mod.hjson 以后不要继续往深检测了**，毕竟可能**有些模组本身就是嵌套的**」
3. 「**不允许一个文件里放两个整个槽**（这个行为目前认为是未定义的，或者把整个槽和其他东西混一起）」
4. 「**或许可以考虑支持混合模式的**」

## 二、已实现（第 379 轮，代码在 `BatchIo` / `DeepLink` / `SlotIo`）

- **优先级**：整槽 > 模组 > 蓝图 > 地图/存档（从"能包住别人"到"只能自己"排）。
- **整槽判据**：只认 `settings.bin`（根上，或**唯一一层**包裹目录里）——
  游戏数据根的标志文件；我们「导出整槽」、脱敏分享包、游戏原生「导出数据」三种来源都带它。
  没有它**不认**（拿"有 `mods/` 目录"当判据会把任何模组整包判成整槽**写入**）。
- **一个包只许一个整槽、且形状干净**（`Probe#slotState()` 四态）：
  没有 ⇒ 不是整槽；≥2 个根有 `settings.bin` ⇒ `SLOT_MULTI`；包裹外面还有别的东西、或包根整槽
  又带着一个一级模组夹 ⇒ `SLOT_MIXED`。后两种 = **未定义** ⇒ `KIND_SLOT_AMBIGUOUS` ⇒
  深链只弹一句「先分开打包」，**不猜着往某个槽里写**。
- **模组边界**：包根 `mod.json` 一命中就停（`probe` 早退）；模组夹里的 `.jar` 属于那个模组，
  批量导入**先试模组夹、再看命中表**（`expand`），嵌套模组不会被拆成独立模组。
- 落点：整槽 ⇒ **槽页**，走既有「导入整槽」流程（确认框 + 更新/补齐/覆盖 + 自动备份 + 写门禁）。

## 三、「混合模式」（未做）候选

用户想讨论的是第 3 条那种包：**一个整槽 + 别的东西**（模块夹 / 散图 / 散蓝图 / 第二个整槽）。
现在是一句「未定义、先分开打包」。

可选实现（按代价从小到大）：

| # | 形态 | 行为 | 代价 / 风险 |
|---|---|---|---|
| A | 整槽 + 松散内容（`.msav` / `.msch` 在根） | 整槽照常导（`SlotZip.routeLoose` 已经把根级 `.msav`→`saves/`、`.msch`→`schematics/`），确认框里把"另外还有 N 条"列出来 | **最低**：其实今天的 `SlotZip` 已经能这么写；只差分类器不把它判成 `SLOT_MIXED` |
| B | 整槽 + 一个/多个**模组夹** | 整槽写完后，再问"这些模组夹要不要也装进这个槽的 `mods/`" | 中：要串两套流程（SlotZip + 模组导入），失败要分开报 |
| C | **两个以上整槽** | 像批量导入那样排队：逐个问"导进哪个槽" | 高：一个目标槽只能落一个整槽；槽名 / 覆盖策略要立规矩 |

## 四、动手前要定的判据（不先定就别写代码）

1. **A 里的"另外还有 N 条"算不算整槽的一部分**？如果根级散图本来就在槽里（`saves/0.msav` 才是
   游戏认的位置），那 A 可能根本不需要"混合模式"——只是分类器别把"根级散图"当混装。
2. **B/C 的目标槽怎么选**：整槽导入是**覆盖/更新/补齐**一个既有槽；再塞模组夹时，用户看到的是
   一个确认框还是两个？失败一个算不算整体失败？
3. **"混装"的界定**：哪些条目属于"整槽的一部分"（`mods/` `saves/` `maps/` `schematics/`
   `settings*.bin` `assetCache/` `previews/` `server_list.json` + 用户自己的杂项目录），
   哪些算"别的"（一级模组夹、根级散落文件、第二个 `settings.bin`）。
   ⚠️ 槽根本来就能有**任意**用户目录（`Data.SLOT_EXCLUDE` 是排除名单）⇒ 不能用白名单判"别的"。

## 五、不做

- **不自动挑一个整槽**（多个整槽时不许"取第一个"）：写错槽是丢数据级别的错。
- 不把"整槽 + 别的东西"静默降级成"只导整槽"或"只导别的"——必须让用户看见并选择。

## 六、当前观测点（真机已验证）

- `settings.bin` + `saves/` + `mods/` + `schematics/` ⇒ 整槽（进槽页，确认框如实列出四项）。
- `A/settings.bin` + `B/settings.bin` ⇒ `KIND_SLOT_AMBIGUOUS`（一句「先分开打包」）。
- 上述行为都有自检钉着（`deepLink()` 那一节）。
