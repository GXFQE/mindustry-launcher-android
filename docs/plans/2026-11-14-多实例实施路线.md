## 不做什么 / 风险边界

- 不做"第一个实例默认、第二个才切每实例"：第一次启动时不知道后面会不会开第二个，状态会分叉。
- 全量 B 补丁 ≠ 换 B APK：native / manifest / versionName 补不了；缓存身份用 `effectiveSig`，但不要把全量补丁当受支持的换版本路径（§12.27）。
- 恶意 mod / 绝对路径 / native 不受 app 层隔离约束：这是"合作式隔离"，不是沙箱（§12.28）。
- `files` / 槽数据 / 导入包**永不自动清**；"重置实例"才动 `files`（§12.25）。
- 系统 cache 只留宿主自身 / 框架不可控部分；我们自己的数据全部搬出（§12.32）。
