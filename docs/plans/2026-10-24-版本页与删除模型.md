# 版本页 + 删除模型（2026-10-24 定方向）

> **已归档（2026-10-25）**：实现与验收正文在 `docs/flows/20-阶段-14-版本多槽.md`；本文件只作设计留档。

> **状态（2026-10-25，已全部落地）**：版本页 + 六动作 + 启动项删除 / 最后一项删版本；
> 已装版最后一项不许删；**导入版本删到最后一项时本体进中转站，可放回**（`Trash.Kind.VERSION`）。
> 删掉「已装版 → 已移除名单」那一段：用户 2026-10-25 定案「已装版本的最后一个实例不能删除」，
> 因此不需要隐藏名单。
>
> 用户 2026-10-24 两句话定的方向：
> ① 「把入口都统一下，怎么已安装版本和导入版本下面按钮咋还不一样」
> ② 「现在可以克隆以后应该不会有人需要频繁换槽，所以把槽这个接口改成二级页面，
>    里面可选各种功能（换槽 / 克隆 / 资源 / 删除 / 详情 / 命名）」
> ③ 「除了来自已安装的版本中的最后一个实例不能删除外，其他功能完全同步（不管来源）」
>
> 本文件是**已定未做**的设计；实现落地后正文进 `docs/flows/20-阶段-14-版本多槽.md`。

## 一、为什么乱（现状）

| 入口 | 现在干的事 | 问题 |
|---|---|---|
| 行上的「槽」 | 换槽 + 看详情 + 再加一行（曾经还有移除） | 三件事挤一个弹窗；"槽"与「存档与备份」同名不同义 |
| 长按版本 | 信息 + 命名 + 删除 + 资源（已装版还多一个「槽」） | 读信息和破坏性动作混在一起；装 / 导入两套按钮 |
| 存档与备份 | 槽本身：改名 / 克隆 / 删除 / 备份 | — |

根子：**"版本"没有自己的页面**，版本级动作只能塞进长按弹窗；"行（启动项）"没有地方管。

## 二、目标：三个概念各归其位

- **行 = 启动项**：主界面一行，点 = 启动；行上按钮 = 进「版本页」。
- **槽 = 数据**：存档 / 设置 / 模组；只在「存档与备份」里管。
- **版本 = 本体**：一个 APK（导入的副本或系统里装的）；在「版本页」里管。

## 三、版本页 `VersionActivity`

入口：行上的按钮（文案改成「管理」）+ 长按行（同一条路，不再分两个弹窗）。
传参：`key` + 这一行的槽（`bound`，主行为空）+ 从哪个槽进来的（用来显示"这一项"）。

布局（ScrollView，风格抄 `SlotActivity`：身份卡 + 动作行 `row_action`）：

```
Mindustry 端 159.7                     ← 标题
官方安装 · 74.7 MB · 12 个存档          ← 副标题（点身份卡 = 详情）
这一项：槽 default · 12 份存档           ← 当前行

换槽…          给这一项换一个槽（单选，只列没被这个版本占用的）
克隆…          用另一个槽再加一项（共用本体，不复制存档）
详情…          来源 / 校验 / ABI / 路径（只读）
命名…          给这个版本起名（已装版也允许，只改显示名）
资源…          导出游戏包资源（现有 ResourcesActivity）
删除…          见第四节（范围随行数变）
```

长按行 = 直接进这一页；主界面不再有"槽选择"弹窗。

## 四、删除模型（引用计数）

- 行就是实例；**删掉这一行**：还有别的行 ⇒ 只删这一行；这是最后一行 ⇒ 整个版本消失。
- 主行也能删：删掉后自动把另一行提上来当主行（`version_slots` 换人）；没有别的行 ⇒ 走"删版本"。
- **删版本**：
  - 导入版 ⇒ APK 副本 + 登记一起进**中转站**（新种类「游戏版本」），能从「中转站」放回来
    （放回 = 文件回 `app_hub/import`、重新登记、名字与槽绑定一起恢复）。
  - 已装版 ⇒ 进「已移除的版本」名单（设置页能恢复）；系统里的包**不动**，想真删去系统里卸载。
- 槽里的存档 / 设置 / 模组：任何删除都**不动**。
- 确认框要写清范围（"只删这一行" vs "删掉整个版本，还有 N 行一起没"）。

## 六、施工顺序（每步都要能构建 + 自检过）

1. `VersionOps` 抽出来 + `VersionActivity` + 布局 + 清单 + `PAGES` 登记；主界面改入口。
2. 行删除（含主行提升）+ 最后一行 = 删版本；导入版进中转站 + 放回。
3. 已装版「已移除」名单 + 设置页恢复。
4. 文案清理、自检、真机验收、文档、记忆。

## 七、验收清单

- 任意一行的按钮/长按都进同一个页面；页面里 6 个动作都在。
- 加一行、删一行、删版本：列表与 `config.json` 对得上；槽里的存档不动。
- 导入版本删除后出现在「中转站 · 游戏版本」，放回后版本与名字/绑定回来。
- 已装版本删除后从列表消失、设置页能恢复、系统里仍安装。
- 两个方向都验：已装 / 导入；主行 / 附加行；最后一行 / 还有别的行。
