# 0.1 清单缺 `INTERNET` 权限 —— 游戏内联网全部失败

**证据**（本机 aapt2 dump，两边对比）：

| APK | 声明的权限 |
|---|---|
| 官方 Mindustry v159.7 | `INTERNET`、`READ_EXTERNAL_STORAGE`、`WRITE_EXTERNAL_STORAGE` |
| 我们的启动器（含探针 `hub-probe-release.apk`） | 只有 `QUERY_ALL_PACKAGES`、`REQUEST_INSTALL_PACKAGES` |

**为什么这一定是 bug**：权限按 **UID** 授予，而游戏代码跑在**我们进程、我们 UID** 里
⇒ 我们没声明 `INTERNET`，游戏代码调用 socket 时就是 `SecurityException`。
后果：多人联机、服务器列表、游戏内置的 mod/地图下载**全部失败**。
（`M2` 只验了"能启动进主菜单"——启动不需要联网，所以这个洞没被那轮测试暴露。）

# ★★ 0.2 已抓到现行（2026-10-01：直接读游戏自己写的日志）

`<数据根>/last_log.txt` 里原话：

```
[E] Failed to fetch community servers: java.lang.SecurityException: Permission denied (missing INTERNET permission?)
	at java.net.Inet6AddressImpl.lookupHostByName(Inet6AddressImpl.java:150)
	...
Caused by: android.system.GaiException: android_getaddrinfo failed: EAI_NODATA
Caused by: android.system.ErrnoException: android_getaddrinfo failed: EPERM (Operation not permitted)
```

⇒ 从"推论"升级为**实证**：联机拉取确实在第一步 DNS 就被 `EPERM` 挡掉。

⚠️ **同时修正此前的一处错判**：此前据"dex 里搜不到这句提示串"推断"游戏会静默失败、不会告诉你原因"。
**这是错的**——`missing INTERNET permission?` 是 **Android framework（`BlockGuardOs`/libcore）抛的**，
不在游戏自己的代码里，所以**去 dex 里搜注定搜不到**（方法论错误，不是事实错误）。
真实情况是：**游戏把它完整记进了 `last_log.txt`，带完整堆栈**——我们只要读那个文件就能看见。
⇒ 教训：*框架抛的错要去看运行期日志，不要指望在应用 dex 里找到字符串。*
详细机制见 `REFERENCE-android-adaptation.md` §14。

**动作**：`INTERNET` 直接加（无运行时申请、无副作用）。
`READ/WRITE_EXTERNAL_STORAGE` 需评估 —— targetSdk 36 下基本已失效，
但游戏代码里有 `checkSelfPermission`/`requestPermissions` 路径，缺声明会让它的运行时请求**直接被拒**；
它拿这两个权限干什么、被拒后是否降级，**待核实**。

**为什么列在 P0**：它同时是下面「嵌入论坛」「下载地图」的前置条件 —— 先补权限再谈这两个。
