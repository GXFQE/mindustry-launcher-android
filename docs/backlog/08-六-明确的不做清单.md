# 六、明确的"不做"清单（省得以后反复讨论）

| 不做 | 原因 |
|---|---|
| 应用内 Java 模组编译器 | 设备上编译 + dex 不现实（要 JDK + d8）；JS 路线已够用 |
| "打开数据目录" | Android 11+ 系统级禁止；用"导出到共享存储"替代 |
| Java 路径 / JVM 参数设置 | Android 无 JVM CLI；游戏自带 natives；槽隔离已替代 `MINDUSTRY_DATA_DIR` |
| "永久删除"开关 | Android 无回收站，这个开关没有意义 |
| 引入 Material Components / androidx | 破坏"零依赖无 Gradle"选型；framework 范围内够用 |
