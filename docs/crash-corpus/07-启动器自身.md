## 7.1 `AttributeError: 'MindustryLauncher' object has no attribute 'config'`

- 首现：2025-11-24 ｜ 出现 1 次
- 来源会话：自动备份游戏存档脚本教程
- 类别：启动器自身 ｜ `Likely Cause`：无
- 注记：**我们桌面启动器自身**的 Python 异常（不是游戏）。

```
AttributeError: 'MindustryLauncher' object has no attribute 'config'
我们遇到了一个错误：在初始化MindustryLauncher时，在setup_gui方法中调用setup_settings_ui时，使用了self.config，但此时config属性还未被初始化。
 这是因为在__init__中，我们先调用了setup_gui，然后才调用load_config来加载配置。因此，在setup_gui中的setup_settings_ui方法中，self.config还不存在。
```

## 7.2 `TypeError: '<' not supported between instances of 'int' and 'tuple'`

- 首现：2026-07-21 ｜ 出现 1 次
- 来源会话：存档备份CAS存储实现
- 类别：启动器自身 ｜ `Likely Cause`：无
- 注记：**我们桌面启动器自身**的版本号解析 bug（MindustryX 版本元组形状不同）。

```
TypeError: '<' not supported between instances of 'int' and 'tuple'
我们发现了错误：在 `get_versions` 中，对于 MindustryX 类型，`_parse_mindustryx_version` 返回的是单个整数的元组，如 `(35,)`，而对于普通版本，解析结果是元组可能包含 `(int, "")` 这样的混合类型。排序时比较会失败，因为两种版本类型的解析结构不同。需要统一排序键的格式，或调整解析方式，使得所有版本都可以比较。
```
