## F25.1 先取证（**结论与传言相反**，取证过程见 REF §91.1）

| 分享什么 | 会漏身份吗 | 漏的是 |
|---|---|---|
| 存档 `saves/*.msav` | ❌ 不会 | 写侧 `extraTags` 留 null（`Saves$SaveSlot$1`），416 份语料 0 命中 |
| 地图 / 蓝图 | ⚠️ 会 | meta 的 `steamid` = **Steam 创意工坊物品 ID**（不是账号 ID）—— **本阶段没做** |

## F25.3 步骤（照这个顺序做，顺序本身是有信息量的）

1. **先算计划、再弹框**：`SharePack.plan(slotDir)` 在**后台线程**跑（解析 5 908 键 / 502 KB 是 IO+CPU），
   回来才弹确认框 —— 框里的"这次会去掉 N 项"**必须真会发生**。
2. 确认框：类别由资源说、条数由代码算；`plan.dropServerList` 为真时多一行。
3. 用户点「选择保存位置」⇒ SAF ⇒ 回调里按 `EXPORT_SHARE` 分派给 `doExportShare`（**那份 plan 就是**要写进包的字节）。
4. 打包走 `Exporter.zipTo(..., SlotIo.shareXform(plan))`：`dropTop(rel)` 丢根级 `server_list.json`、
   `bytesFor(rel)` 换 `settings.bin`。
5. 完成提示两个出口分开：`share_slot_done_fmt`（去掉了 N 项）/ `share_slot_done_clean_fmt`（本来就没有）。

## F25.5 坑（都是本轮真踩/真定下来的）

1. 🔴 **"已脱敏"是承诺** ⇒ `settings.bin` 读不出来就**拒绝导出**（界面不启动 SAF、dev 口不打包），
   别做"原样塞进去 + 小字提示"。
2. 🔴 **逐条目钩子的参数必须是相对路径**（`rel`）而不是 `File` —— 给 `File` 会被写成
   `getName().equals(…)` = **任意深度都命中**（会改到模组目录里的同名文件）。
3. **别为分享包另写一份目录遍历**：整槽导出那条路上有三处口径（打什么 / 跳过什么 / 条目名怎么拼）。
4. `Values` 的**删除也要保序** —— 否则"本来没有敏感键 ⇒ 字节差 0"这条元断言立不住。
5. 弹窗新项**加在最后**：老两项的下标（0/1）一个都不动，任何"按下标点第几项"的老断言不受影响。
6. 分享包**仍然能被游戏导入**（根上有 `settings.bin` 是游戏 `importData` 的硬要求）。
