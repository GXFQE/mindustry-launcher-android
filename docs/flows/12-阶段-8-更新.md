## 阶段 8：更新（优先级已下调）

### M4a —— 游戏版本更新（低难度，可提前）

**★ M1 的 `Importer` 已经做完 90%**（流式拷贝 + zip/`version.properties` 校验 + 预热预检 + 只读落盘 + 配置登记）。
要新增的只有三件：**下载器 + 版本源表 + 镜像前缀**。

- 版本源表结构**对齐桌面版 `launcher/sources.py`**（一张表，内置源 + 用户可加/覆盖），配置落在 `Config` 里。
- ★ 国内网络下载 GitHub Release 需换镜像。
- 下载完成后**直接走 `Importer` 的落盘路径**（不要另写一套），这样"导入的 APK"和"下载的 APK"在数据模型里是**同一种东西**。

### M4b —— 启动器自更新（难 + 有前置）

⚠️ **两个硬约束，别忘了**：
1. ★ **签名密钥必须先换成正式的** —— PackageInstaller 的四道闸门里有"签名一致"，
   现在还是 `debug.keystore`，**一旦发布过自更新就换不了了**（换了老用户收不到升级）。
   ⇒ 这是 M4b 的**唯一真前置**，可以在 F1~F14 期间顺手先换掉。
2. 包名 `io.mdt.launcher` **已实质定稿** —— 数据根绑定包名，M1 用户一旦产生数据就改不得。

- 实现走 `PackageInstaller` 会话（四道闸门 + 回调坑），**不能**用 `ACTION_VIEW` 甩给系统安装器（会被某些 ROM 拦）。
- 更新策略（自动 / 只提示 / 关闭）在 F3 里先落配置，行为后补。
