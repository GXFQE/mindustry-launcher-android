## 零、通用约定（每个功能都适用，先读这一节）

### 0.1 工程现状（决定了下面很多步骤）

| 事实 | 影响 |
|---|---|
| ★ `app/res/` **已接上**（F1，2026-10-01） | `strings` / `colors` / `themes` + `values-night/` 已可用，`build.sh` 的 `[1/4]` 已含 `aapt2 compile`。**以后新增 layout / drawable 直接放进 `app/res/` 即可，build.sh 不用再动** |
| 纯 framework，零依赖，无 Gradle | 不引 AndroidX / Material；`ListView`+`BaseAdapter` 是既定范式 |
| 包名 `io.mdt.launcher` **已定稿** | 数据根绑定包名 ⇒ 改包名 = 用户数据全丢，**不要再动** |
| 签名仍是 `debug.keystore` | **M4b 发布前必须换**；发布过自更新的包换不了签名 |
| UI 统一模式 | `Activity` → `onCreate` 里 `buildUi()` → `onResume()` 里 `refresh()`；`Adapter extends BaseAdapter` |

### 0.2 构建 / 安装 / 验证链（每次改完都走一遍）

```bash
cd <本工程根目录>
./build.sh install                     # 构建 + adb install -r
# 开发期要开 dev_* 直通口（见 0.3）：
DEBUGGABLE=true ./build.sh install
```

- 干净构建 ≈ **74131 B**（F1 后基线；接入 res/ 前是 57747 B。`ls -la mdt-launcher.apk` 看一眼，尺寸异常基本就是没打进去）。
- ⚠️ **不能 `rm -rf build/`**（构建脚本刻意不 `rm -rf`，只做改名归档）⇒ 用 `./build.sh clean-trash` 或整个 `mv` 走。
- ⚠️ **用 Git Bash 时** `adb` 命令要加 **`MSYS_NO_PATHCONV=1`**（PowerShell / CMD 不需要；加它是防 Git Bash 改写设备路径）。
- ⚠️ 本 ROM **滤掉 main logcat** ⇒ 排障第一站是 **`adb logcat -d -b crash`**（可读，有完整堆栈）；
  其余证据一律**写文件**再 `adb pull`/`cat`。

### 0.3 `dev_*` adb 直通口（现成的自动化测试通道）

`MainActivity.checkDevIntent()` 已实现一批入口，**只在 debuggable 构建里生效**（发布构建会 Toast 拒绝）：

```bash
ADB="$ANDROID_HOME/platform-tools/adb.exe"; export MSYS_NO_PATHCONV=1
"$ADB" shell am start -n io.mdt.launcher/.MainActivity --ez dev_m3_selftest true   # 跑 M3 自检
"$ADB" shell am start -n io.mdt.launcher/.MainActivity --ez dev_saves true         # 直接进存档页
"$ADB" shell am start -n io.mdt.launcher/.MainActivity --es dev_launch_key <key>   # 走完整点击路径启动
"$ADB" shell am start -n io.mdt.launcher/.MainActivity --ez dev_health true        # 数据根体检
"$ADB" shell am start -n io.mdt.launcher/.MainActivity --es dev_msav_path <p> --es dev_msav_slot <s>
```

★ **新功能一律顺手挂一个 `dev_xxx` 口**：不然就只能靠手点，回归成本立刻爆掉。
`SelfTest.runM3(ctx)` 返回文本报告（含 md5 破坏/恢复一致性断言），是"非 GUI 断言"的范式，照抄它。

### 0.4 新增一个页面（第三页开始照这个抄）

`SavesActivity` 是现成模板，骨架固定为：

```
class XxxActivity extends Activity {
    onCreate  → setContentView(buildUi());  Util.applySystemInsets(root);
    onResume  → refresh();                    // 回前台自动刷新，天然满足"游戏退出后回到启动器并刷新"
    buildUi() → 顶部 TextView(标题/信息) + ListView/按钮区
    refresh() → 读数据 → 更新 Adapter
    alert(title,msg) / toast(s) / dp(int)     // 工具三件套
    Adapter extends BaseAdapter               // 硬编码布局，别用 simple_list_item_*
}
```
清单里加 `<activity android:name=".XxxActivity" android:parentActivityName=".MainActivity"/>`；
入口放 `MainActivity.buildUi()` 的按钮区；然后**同步加一个 `dev_xxx` 口**。
