## F24.0 一句话

四类内容都支持"**一次勾多份**"：

```
导出：勾 1 份 = 老样子（直接给那个文件，文件名就是原文件名）
      勾 ≥2 份 = 一个 zip（外层 zip 里每一条 = 单份导出时用户会拿到的那个文件）
导入：选 1 个普通文件 = 老样子（存档仍会问名字、同名仍逐个问）
      选 ≥2 个文件、或者选了 .zip = 批量（按原文件名落位，同名只问一次）
```

★ **导出的 zip 能被同一套批量导入吃回去**（真机往返验过：136 张地图 md5 逐份相同）。

## F24.2 动手顺序（照这个顺序改，别跳）

1. **`Exporter` 那层先做**：`Src` 三种来源 + `zipSources`。判据只有三条 ——
   条目名**唯一**（`x.msav` / `x (2).msav`）、字节**逐字节**、目录形态要能被**再打开**
   （嵌套 zip）。这三条都能用 `ByteArrayOutputStream` 在自检里钉死，**不必上真机**。
2. **`BatchIo` 的纯函数部分**：`plan`（批内去重 + `dest.exists()`）、`bundleNames`、
   `extractBundle`（只取 basename）。同样先自检。
3. **`BatchIo` 的界面部分**：`pickFiles` / `docsOf` / `pickMulti` / `startExport` /
   `handleExportResult` / `runImport`（规划 → 问一次同名 → `applyAll` → 报告）。
4. **四页接线**：每页只做三件事 —— 入口换成 `BatchIo.pickFiles`、`onActivityResult` 里
   分"1 份普通文件 vs 批量"、导出的勾选回调里分"1 份 vs 一个 zip"。
   ⚠️ 别忘了 `onActivityResult` 里加 `BatchIo.handleExportResult(...)`（漏了 = 选完保存位置没反应）。
5. **资源**：`values/`（英文，**默认目录，先写这里**）+ `values-zh/`，占位符序号必须一致。
6. **自检 + 真机**：见 §5 / §6。

## F24.3 判据表（照这个读代码）

| 判据 | 在哪 | 反向 / 元断言 |
|---|---|---|
| 条目名唯一 | `Exporter.uniqueName` | 两份同名 ⇒ 两个条目（自检） |
| 一条都没有 ⇒ 拒绝 | `zipSourcesTo` 的 `written == 0` | 空清单 / 源全不存在（自检两条） |
| `Result.files` = **几份**（不是几个文件） | `zipSourcesTo`（目录内层另用计数器） | 3 条必须报 3（自检；实测曾报 5） |
| "整包" = 认后缀 **且** 包根没有模组说明文件 | `BatchIo.bundleNames` | 模组包（带 `mod.hjson`）必须判**不是**整包 |
| 解包只取 basename | `BatchIo.extractBundle` | 带子目录的条目落下后**在工作目录里** |
| 批内重名撤掉 / 与槽里同名只问一次 | `BatchIo.plan` + `runImport` | 空目录 ⇒ 同名 0（元断言） |
| 四种出口一条都不许静默吞 | `BatchIo.Report` + `applyAll` | 不是模组的包 ⇒ 计入**失败**并点名 |
| 目录形态 = 嵌套 zip | `Exporter.addTreeAsZip` + `NonClosing` | 外层那条必须能被 `ZipFile` 打开 |

## F24.4 踩过的坑（这一轮真踩的）

* 🔴 **内层 `ZipOutputStream.close()` 会连外层一起关掉**（后面的条目全没了、而且**不报错**）
  ⇒ 目录形态要包一层"只 flush 不 close"的 `NonClosing`。
* 🔴 **`Result.files` 的语义**：它是"这一批有几**份**"（界面「已导出 N 份」直接读它），
  目录内层的文件数不能计进去（自检第一版断言 3、实测 5）。
* 🔴 **资源参数传反不会编译报错**：`batch_note_unpacked_fmt` 是 `%1$d … %2$s`，
  调用点写成 `(name, size)` ⇒ `IllegalFormatConversionException`，真机批量导入 zip 直接崩。
  （门禁 `RES-02` 只比对**占位符序号集合**，管不到调用点顺序。）
* ⚠️ **`ZipOutputStream` 不让造 `../` 条目**（`Invalid zip entry path`）⇒ 路径穿越那条防线
  在自检里只能靠"带子目录的条目"间接钉（同一行代码）。
* ⚠️ **dev 口有白名单**：`dev_batch_export` / `dev_batch_import` 漏加 key ⇒ 命令静默无反应（老坑）。
* ⚠️ **SRC-02 台账要跟着改**：往 `MainActivity` 的 dev 口加中文 ⇒ 156 → 165（同族，注明理由）。
