## 阶段 3：深链（★ 性价比最高）

### F9 —— 深链 intent-filter

**目标**：用户在浏览器 / 任何 App 里点一个 `.msav` 链接或文件 → 系统直接把文件交给我们的启动器导入。
**零 WebView、零网络代码、零新原语。**

**现状是漏项**：我们从官方 APK 抄了 `mindustry.android.AndroidLauncher` 的**属性**，
但**三组 intent-filter 一个都没抄**，且 `exported="false"`。

**改动面**：`app/AndroidManifest.xml` 的 `<activity android:name="mindustry.android.AndroidLauncher">`。

**要照抄的四组**（官方原样，`aapt2 dump xmltree` 得来）：

```
filter1  MAIN + LAUNCHER
filter2  VIEW + DEFAULT + BROWSABLE   data scheme="mindustry"
filter3  VIEW + DEFAULT + BROWSABLE   data scheme="content"
                                      + mimeType="application/octet-stream"
                                      + mimeType="application/x-msav"
filter4  VIEW + DEFAULT + BROWSABLE   data scheme="file" host="*"
                                      + mimeType="*/*" + pathPattern=".*\.msav"
```

**步骤**
1. `exported` 改 `true`（⚠️ 安全面要一起想清楚，见坑）。
2. 四组 filter 抄进去；`launchMode=singleTask`、`process=":game"`、`orientation`、`configChanges`、`resizeableActivity` **与官方一致，不用动**。
3. 游戏侧处理**官方已经写好了**（`AndroidLauncher.handleIntent`，我们只是转发）：
   `mindustry://` → 弹确认 → `ui.join.connect(host, port?6567)`；`content://`/`file://*.msav` → 落 `cache/imported` → `ClientLauncher.handleFileImport`。
   ⇒ **我们一行逻辑都不用写**，只补清单。
4. ⚠️ 注意是 `onNewIntent` + `ClientLoadEvent` 两处触发 ⇒ 冷启动（游戏还没起来）和热启动都要测。

**验收（必须实跑，不能只读清单）**
```bash
# 冷启动：先 force-stop
"$ADB" shell am start -a android.intent.action.VIEW -d "content://..." -t "application/octet-stream"
"$ADB" shell am start -a android.intent.action.VIEW -d "file:///sdcard/xxx.msav" -t "*/*"
"$ADB" shell am start -a android.intent.action.VIEW -d "mindustry://host:6567"
```
逐条确认：能拉起我们的包、能落到 `handleIntent`、`.msav` 真的进了导入流程。

**坑**
- ⚠️ `exported=true` + `VIEW/BROWSABLE` 意味着**任何 App 都能拉起我们的游戏 Activity 并塞数据**。
  这份"数据"是 `.msav` 文件 ⇒ 必须确保**导入路径本身是安全的**（大小限制、zlib 魔数校验、目标槽不越权），
  不能假设数据可信。这是**唯一需要认真想的风险点**，也是为什么 M5 前要复评是否收回 `exported`。
- ⚠️ `file://` 在现代 Android 上从浏览器发出会带 `FileUriExposedException` 风险 —— 要测真机实际行为，
  浏览器多半不发了，但**文件管理器点文件**仍走这条路。
- ⚠️ `pathPattern=".*\.msav"` 在 XML 里要写 `.*\.msav`（反斜杠不转义），抄官方原样。
