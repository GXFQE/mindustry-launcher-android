## 阶段 5：地图下载 / 论坛嵌入

### F11 —— 从 www.mindustry.top 下载地图

**目标**：浏览地图列表 → 下载 `.msav` → 自动放进指定槽的 `saves/`。

**已核实**：**干净 REST JSON API**（不是 HTML 抓取），端到端闭环已通（id=25765 → 41392 B → 解析成功）。

```
GET https://api.mindustry.top/maps/list?page=N   → JSON，每页 15 条
       字段：id, name, desc, latest, preview, tags, width, height, mode
GET https://api.mindustry.top/maps/{id}.json     → JSON，字段：hash, name, tags, preview, user, mode, thread
GET https://api.mindustry.top/maps/{id}.msav     → application/zlib（历史上有 302 → ipfs.mindustry.top，**两种都要能跟**）
```

**前置**：F9（可选，但有了更顺）、F10（预览/校验）、`INTERNET` 权限（✅ 已补）。

**改动面**：新 `MapBrowserActivity` + 新 `Http.java`（薄封装）+ `Msav.stage/commit` 复用。

**步骤**
1. 网络层：`HttpURLConnection`（**不引 Retrofit/OkHttp**，保持零依赖）。
   - 设 **UA**（有些源会挑 UA）、设 `connectTimeout/readTimeout`（各 10 s）、处理 **302**（`setInstanceFollowRedirects(true)`，并允许 http→https 与跨域，`ipfs.mindustry.top` 是另一个域）。
   - **必须在后台线程**（`mExecutor`），Android 主线程不允许网络。
2. 列表页：`/maps/list?page=N` → 列表项显示 `name` + 尺寸 + tags；**预览图用 `preview` 字段**（是图片 URL）。
   ★ **省流量**：详情预览**不用下载 `.msav`** —— `/maps/{id}.json` 的 `tags` **就是完整的 `.msav` 元数据表**（`mods/name/tick/wave/build/rules`），一个 JSON 就够。
3. 下载：流式写入临时文件 → 校验 **zlib 魔数**（`78 01`/`78 9c`/`78 da`）→ 用 **`Msav.stage` → `Msav.commit`**（两段式，**零新原语**）落到用户选的槽的 `saves/`。
4. 文件名：用 JSON 里的 `name` 走 `Msav.safeName`（**保留非 ASCII**，文件名非法字符才替换）。
5. 错误态：超时/404/魔数不符 → 明确提示 + 可重试；别只 `toast("失败")`。

**验收**
- 真机下载 3 张不同尺寸的地图，游戏内**能直接打开**。
- 断网 / 改 DNS 到黑洞，超时后在 10 s 内给出可读错误，不 ANR。
- 下载途中杀进程，`saves/` 里**没有半个残文件**（这就是 `stage/commit` 的意义）。

**坑**
- ⚠️ 302 → ipfs 是**跨域**，别只跟同域重定向。
- ⚠️ 别把整张地图读进 `byte[]`（有的 300×300 地图几 MB，mods 地图可能更大）⇒ 流式。
- ⚠️ 落到 `saves/` 属于**写用户存档目录** ⇒ 必须走 `Data.savesDirOf(ctx, slot)`，**不硬编码路径**（槽可能要交换）。

### F12 —— 嵌入 mdthub.fun（论坛）+ 窗口形态

**目标**：应用内开网页，且**能与主界面/游戏同时存在**（"像微信和微信小程序一样"）。

**前置**：F9（自定义 scheme 桥接同构）、`INTERNET`（✅）。

**已裁决的形态**（探针真机实测 + 15 张截图）

| 形态 | 两窗口同屏 | 同时可交互 | 跨 App | 权限 |
|---|---|---|---|---|
| ③ `PopupWindow` + WebView | ✓ | ✗ **点矩形外即 dismiss** | ✗ | 无 |
| **④ `TYPE_APPLICATION_PANEL`** | ✓ | ✓ | ✗ | 无 |
| **⑥ `TYPE_APPLICATION_OVERLAY`** | ✓ | ✓ | ✓ 浮在满屏 Mindustry 上 | `SYSTEM_ALERT_WINDOW` |

**⇒ 产品形态：L0 `ACTION_VIEW` 交浏览器（0 代码） → L1 形态 ④ 内置浮窗 → L2 形态 ⑥ 跨 App 悬浮窗（默认关的开关）。**

**改动面**

| 文件 | 做什么 |
|---|---|
| `app/src/io/mdt/launcher/WebActivity.java` | 新建，WebView 壳（抄 MDTHub 官方 App 的形态，37 KB 就能跑） |
| `app/src/io/mdt/launcher/FloatingWeb.java` | 形态 ④ / ⑥ 的 `WindowManager` 子窗口封装 |
| `AndroidManifest.xml` | `SYSTEM_ALERT_WINDOW`（**只在 L2 需要**）+ `WebActivity` |

**步骤（L1：形态 ④）**
1. `WebView` 壳：`onPageFinished` 里做该做的事（**每次**，SPA 换页会重建 DOM），顺手 `CookieManager.flush()`。
2. 配置：`setAcceptThirdPartyCookies(webView, true)`；UA 幂等追加（`if(!ua.contains("MDT-App")) ua += " MDT-App/<ver>"`）。
3. **web→native 用自定义 scheme，不要 `addJavascriptInterface`**：
   `shouldOverrideUrlLoading` 里 `if(u.startsWith("mdt://...")) { ...; return true; }`；站内留 WebView，站外甩 `ACTION_VIEW`。
   —— 与我们游戏自己的 `mindustry://` 深链**天然同构**，一套思路两处用。
4. 形态 ④ 落地：`WindowManager.addView(view, lp)`，`type = TYPE_APPLICATION_PANEL`，
   `flags = FLAG_NOT_TOUCH_MODAL`（**矩形外穿透、矩形内正常**），
   ★ **`token` 必须是 `decorView.getWindowToken()`** —— 写成 `getWindow().getAttributes().token` 会崩
   `BadTokenException`（实测撞过）。
5. 关窗时 `removeView`，`Activity.onDestroy` 里兜底再 `removeView`（防泄漏）。

**步骤（L2：形态 ⑥，独立开关，默认关）**
1. `type = TYPE_APPLICATION_OVERLAY`、**`token = null`**（跨 App 悬浮窗不要 token）、`FLAG_NOT_FOCUSABLE`。
2. 权限门：`SYSTEM_ALERT_WINDOW` **不是 runtime permission** ⇒ `pm grant` 无效、没有运行时弹窗，
   只能走 `Settings.ACTION_MANAGE_OVERLAY_PERMISSION` 跳系统设置手动开。
3. ⚠️ **绝不能首次启动就弹授权** —— 被差评的经典死法。做成"设置页里的一个开关，用户主动点才申请"。
4. Activity 销毁时必须 `removeView`，**否则窗口泄漏到全系统**。

**下载（★ 头号大坑）**：`DownloadManager.Request` 里必须
`addRequestHeader("Cookie", CookieManager.getCookie(url))` + `addRequestHeader("User-Agent", ua)`
—— **不透传 Cookie 的话，登录态下载 403**。这是套壳下载最容易翻车的一点。

**验收**
- L1：主界面点"论坛"→ 浮窗出现；**同时能点主界面按钮**（这是 ④ 的核心断言）；关窗正常。
- L2：开启后启动官方 Mindustry（满屏），浮窗**仍在游戏之上**且渲染完成；关闭有效。
- 网页内登录一次，**下次进不用再登**（cookie 持久）。
- 登录态下点下载，**不 403**。

**坑（不抄清单，来自 MDTHub 官方 App 拆解）**
- ❌ **不要抄它的 `injectCSS`**：把它的选择器原样注入真实首页，**命中元素数 = 0**（人家改版把那个横幅删了）。抄一个命中 0 的补丁 = 纯负债。
- ❌ `setDestinationInExternalPublicDir(DOWNLOADS, …)` + `MANAGE_EXTERNAL_STORAGE` —— 它落公共目录才要这个商店敏感权限；
  我们落**当前槽的 `saves/`**，走 M3 两段式，**完全不需要**。
- ❌ `setAllowFileAccess(true)` / `setMixedContentMode(ALWAYS_ALLOW)` / `setJavaScriptCanOpenWindowsAutomatically(true)` —— 对 https 站点纯放松。
- ❌ 只签 **v1** ⇒ targetSdk 34 + Android 14 起**必须**至少 v2（**反面教材**：我们的 `build.sh` 必须保持 v2+v3）。
- ⚠️ **系统级并排在这台设备上做不到**（实测被 ROM 降级：`--windowingMode 3/6` 都返回整屏 bounds，`5` 被完全忽略）⇒ **别为分屏做设计**。
- ⚠️ **WebView 有独立 cookie/localStorage** ⇒ 用户得在应用内**重新登录一次**，UI 上必须提示，否则会被当成 bug。
